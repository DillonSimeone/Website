For Lab 3, you will write a program that continually accepts numeric and string inputs from a user until they are done. Your program will print an error if the user enters invalid input and prompts the user again. When the user finishes entering in values, your program will perform calculations and print output.

As long as your program satisfies the requirements listed below, you are free to design and write any program that you want to. You are encouraged to be creative and pick something that has meaning for you because you'll have more fun. Look at the miles per gallon and test scores examples in Chapter 3 of the textbook for inspiration. Your program may not use any example from the textbook or lecture. You may use one of the suggestions below:

Prompt the user for a list of food items and when they are done, print the total and calculate suggested tip amounts of 10%, 15%, and 20%. Input the amount, add to the total and print a receipt.
Prompt the user for a list of scores for your favorite game, when they are done, calculate meaningful statistics.
After completing this assignment, you will be able to:

Use an accumulator variable to store user input
Use a loop to continually ask a user for input until they are done
Use conditional statements to validate use input (i.e., money amounts are positive, test scores are between 0 and 100, gpa’s are between 0 and 5.0)
Task
Your program must include the following requirements:

Accept a numeric value and a string value (at a minimum, can be more) as input from the user using input().
Use a loop to prompt the user for input until they are done.
Use a conditional statement to validate the input.
Use an accumulator variable in the loop to sum the numeric input.
Perform appropriate calculations on the numeric input when they are done (i.e., calculate the average, print receipt with tax and shipping, total a restaurant receipt and calculate and print tip suggestions for 10%, 15%, 20%, etc.)
Use an outer loop to ask the user if they want to run the program again with new input.
In the comments box of your submission, answer the following question: Suppose you are writing a program that prompts a user for their age. How would you validate the input? What invalid input would you want your program to handle?
