Partner Lab 5 - Data Structures

Lab 5 is a partner programming assignment - you may complete it with another student from your study group.
Purpose

For Lab 5, you and your partner will write a program containing a list or dictionary and add to, delete, and edit the items.

As long as your program satisfies the requirements listed below, you are free to design and write any type of program that you care to. You are encouraged to be creative and pick something that has meaning for you because you'll have more fun. You can download and run the Sandwich Program as an example of a program that satisfies the requirements below. You may not edit the code to start your lab. You may also want to look at the programming exercises from Chapters 6 or 12 for ideas, but please do not copy the exercises.  

After completing this assignment, you will be able to:

    Use a data structure (list or dictionary) to store a collection of items
    Add and delete items to the data structure
    Use loops to process items in the data structure

Task

Using Replit, create a Python program and share an invite link with your partner. Your program must include the following requirements:

    Your program must use at least one list or dictionary.
    Your program must contain at least three files: the driver program with the main() function and two other module files written by each partner. You must use the import statement to import the module files into the main driver program.
    It must validate the user input. This means the user is not allowed to enter any value. Instead, you must check the value and if it is invalid, ask the user to enter it again and repeat this loop until the user enters a valid value.
    Your program must not crash on any input. This includes entering non-numeric input when your program asks for a number and 0 inputs if your program is doing division.
    Your program must use at least one loop to access the list data in a meaningful way.
    It must use at least two "if" decision structures to access the list data in meaningful ways.
    Your program must make changes to the list or dictionary data, i.e., if your new list is printed, the changes must be visible.
    Organize the code into separate functions: one function for input, one function for output, and one function for each separate calculation or action that the program performs. Each function should be "cohesive" and should only do one thing.
    Use parameters and arguments to pass values into your functions (don't use global variables).
    In the comments box of your submission, answer the following question: Explain the difference between lists, tuples, and dictionaries. Give an example of when you would use each data structure type in a program.

Criteria for Success

    Run your program and test with different user input. Do your prompts explain what the user should enter?
    Take a look at your user interface (UI) and user experience (UX). Did you provide a welcome message letting the user know what to expect? Is the UI nicely spaced with no typos? 
    Please open and compare your work with the Lab 5 Rubric before submitting.
    Remember to follow all Python Style Guide rules for CIS 133Y.
    Include the required comment header with both student names and add comments throughout the code identifying which parts of the program each partner worked on.
    Programs without comments will not be graded - you will be asked to resubmit them with comments before being graded.
    Each student must upload a zip folder with a completed lab5.py file and all other module files to the Lab 5 assignment in D2L and answer the submission question posted on the assignment in D2L.
