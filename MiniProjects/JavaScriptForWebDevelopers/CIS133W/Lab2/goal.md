Overview

The goal of this lab is to create the main homepage for your item manager project. This page will serve as the central hub for your application. You will create a personal introduction and, most importantly, use JavaScript to dynamically generate a gallery of item thumbnails from data stored in your code. This lab focuses on foundational skills like array manipulation, for loops, and basic DOM interaction by generating HTML content.
Learning Outcomes

On completion of this lab, you should be able to:

    Create and manage data using parallel arrays.
    Organize a web project with appropriate subfolders for assets and linked pages.
    Use a for loop to iterate through arrays.
    Dynamically generate HTML content as a string in JavaScript.
    Use the .innerHTML property to add generated content to a webpage.

Task and Requirements

Build a homepage that includes a brief bio and a gallery of clickable item thumbnails. The gallery must be generated by a JavaScript loop reading from three parallel arrays. Here is a list of suggested steps:

    Project Setup:
        First, decide on a theme for your application. Will you manage a list of movies, video games, cars, or books? Be creative! This choice will guide your folder and variable names.
        Create a main project folder Lab2-Gallery. Inside the folder.
        In your main project folder, create a subfolder named assets. Inside assets, create subfolders named images, css, and javascript.
        Place a few placeholder thumbnail images in the images folder that match your theme. You can use whatever images you want, but it's best if they match your theme (movies, cars, etc.). Be sure to include a thumbnail for your calculator if you plan to use it in your list of items. Optional: pick a standard size for your thumbnails and crop/scale/resize your images to fit. This will make the gallery of thumbnails look better.
        Create an items folder inside of your main project folder. Inside the items folder, create a separate subfolder for each item you plan to list (e.g., a calculator folder for your Lab 1 project, a the-matrix folder if you chose movies, etc.).
        Inside each item subfolder, create a simple index.html file. This page only needs a <title> and an <h1> with the item's name for now.
        Create three new files: index.html in the main project folder, gallery.css inside the assets/css folder, and gallery.js inside the assets/javascript folder.  Set up the basic HTML document structure (doctype, html, head, body) in index.html. Include a <title> tag in the head with the name of your item manager. Link to the stylesheet in the head and link the JavaScript file in the body
    Create Your Data (in your .js file):
        Create three separate "parallel" arrays. The data at index 0 in each array should all relate to the same item. You should name these variables to match your chosen theme (e.g., movieNames, carNames), but here is a generic example:
        itemNames: An array of strings for your item titles (e.g., "Simple Calculator").
        thumbnailUrls: An array of strings for the file paths to your thumbnail images (e.g., "assets/images/calculator.png").
        itemUrls: An array of strings for the file paths to your item detail pages (e.g., "calculator/index.html").
        Make sure your Lab 1 calculator is the first item in all three arrays (if you plan to include it). Add at least two other placeholder items relevant to your theme.
    Write the JavaScript Logic:
        In your main index.html file, create a <div> with an id (e.g., id="galleryContainer") where your thumbnails will appear.
        In your gallery.js file, get a reference to that container <div> using document.querySelector().
        Write a for loop that starts at 0 and runs for the length of your itemNames array.
        Inside the loop:
            Create an HTML string for one thumbnail. It should be an <a> tag that wraps an <img> tag.
            The href for the <a> tag should come from your itemUrls array at the current loop index.
            The src for the <img> tag should come from your thumbnailUrls array at the current loop index.
            Use the += operator to append this new HTML string to the innerHTML of your gallery container <div>.
    Add Content:
        In your main index.html file, add your personal bio, your name, and any other introductory content you wish.
        Optional: Add styling information to gallery.css to improve the appearance of your page. You could also use this to define a thumbnail class for your thumbnail images and set a fixed width and height in the stylesheet.

Rubric:

    Project Structure (20%): Correct folder and file organization is in place for assets and item pages.
    Data Structure (25%): Three parallel arrays are correctly implemented with matching data for at least three items.
    Dynamic Generation (40%): JavaScript correctly uses a for loop to iterate through the arrays and generate a gallery of clickable thumbnails. All links work correctly.
    Content & Style (15%): The homepage includes a personal bio and is styled with a basic CSS stylesheet.
