Dual-Tier Polling Engine

Combines zero-overhead 45-second light RSSI/gateway pings with configurable periodic or anomaly-triggered speed tests to minimize data usage.

Root-Cause Anomaly Detection

Instantly flags speed drops below 5 Mbps, determines whether the issue is local RF noise, gateway lag, or an app hogging sockets, and sends a Windows toast alert.

1-Click Network Stack Repair

Includes built-in single-click routines to flush DNS caches and reset the Winsock / IP catalog when system network stacks become corrupted.
