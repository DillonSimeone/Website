# Thresholds — DaSiWa MiniMax H3 Video Prompts
### Mythic Surrealism & Dreamcore Edition (Text-to-Video)

This document contains specialized **Text-to-Video (T2V)** prompt blocks engineered specifically for **DaSiWa MiniMax H3** (Hailuo Video). 

Each threshold is designed under a **Mythic Surrealism & Dreamcore** aesthetic—featuring heightened liminal spaces, impossible physics, shifting ethereal geometry, and supernatural lighting phenomena that honor the cultural motifs of transition and departure.

## 🎛️ Recommended DaSiWa MiniMax H3 Parameters

| Parameter | Recommended Setting | Purpose |
| :--- | :--- | :--- |
| **Generation Mode** | **Text-to-Video (T2V)** | Unconstrained cinematic generation from pure text |
| **Aspect Ratio** | **16:9** (1920×1080 or 1280×720) | Matches fullscreen `object-fit: cover` stage |
| **Motion Strength / Scale** | **5 – 6.5** | Keeps ethereal dreamcore fluid without morph glitching |
| **Duration** | **6s – 10s** (loop / auto-extend) | Web player handles smooth loop & fade transitions |
| **Export Format** | **MP4 (H.264 / AAC)** | Universal browser hardware acceleration |
| **Target Directory** | `public/MiniProjects/Thresholds/assets/videos/` | Instant auto-detection by `app.js` |
