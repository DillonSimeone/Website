Glassmorphism Google Calendar Widget

How It Was Engineered: A zero-framework, client-side event feed widget designed to integrate public Google Calendar feeds directly into modern frosted-glass web layouts. It directly queries the Google Calendar REST API v3, parses iCalendar (RFC 5545) recurrence strings via rrule.js, evaluates future recurrences within a 31-day sliding window, sorts all events chronologically, and renders responsive cards with expandable detail drawers and dynamic pastel theme palettes.

Current Status: The original community calendar (Woodstock Cafe) and production API key have expired. The client script below automatically detects when the live API fails or returns no items, gracefully falling back to embedded sample data so visitors can interact with the glassmorphism layout, recurrence expansion, and detail drawers as originally conceived.
