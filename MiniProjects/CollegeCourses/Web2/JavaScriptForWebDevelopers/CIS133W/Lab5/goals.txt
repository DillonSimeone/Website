Lab 5 Assignment Instructions: Debugging the Carousel
Overview

In Lab 4, you created a dynamic, interactive gallery or carousel to display your items. In this lab, you’ll practice debugging by finding and fixing errors that were intentionally added to these Lab 5 student files which is a completed, but broken version of Lab 4 (do not use your own Lab 4 files for this assignment). You should have completed Practice 7-1 and Lab 4 prior to starting this lab.
Learning Outcomes

On completion of this lab, you should be able to:

    Identify and fix syntax errors that prevent code from running.
    Diagnose runtime errors using browser console messages (e.g., ReferenceError, TypeError).
    Detect logic errors by observing incorrect output or behavior.
    Correct type errors caused by applying methods or properties to the wrong data type.
    Document debugging work with clear comments that explain the error, the problem, and the solution.
    Create and follow a test plan to verify fixes with valid and invalid cases.

Step 1: Debug the code

Each of the three JavaScript files contains one or more errors. The errors include:

    2 syntax errors – code that won’t load at all until fixed
    2 runtime errors – the page loads, but clicking a button or running a feature causes a crash
    1 logic error – the page runs without crashing, but doesn’t behave correctly
    1 type error – a method is called on the wrong kind of object

Note: While we describe these generally as “runtime errors” in the instructions, in the console you will actually see more specific errors such as ReferenceError or TypeError.

Use your browser’s developer tools (F12) to locate and diagnose the problems. Fix the errors one by one until the app works correctly again.
Step 2: Comment your fixes

Above each fix in the JavaScript files, add a multi-line comment that explains:

    Type of error (syntax, runtime, logic, type)
    Problem (what was wrong)
    Solution (what you did to fix it)

Example comment format:

/* 
Type of error: Syntax error
Problem: Forgot to close the parentheses on the function call
Solution: Added missing closing parenthesis to fix the syntax
*/
myWhatever();

Step 3: Write a test plan

Create a text file named test_plan.txt. In this file:

    List each error you fixed.
    Describe how you tested the program to confirm that the error was resolved.
    Include both valid and invalid test cases where appropriate.

Rubric

    Errors Corrected (60%): All 6 errors were found and corrected in the code.
