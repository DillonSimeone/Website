Firmware Setup & Hardware Flashing Guide

To run a HAXEL ESP-NOW mesh fleet, you need 1 Master node and 1 or more Follower nodes (e.g. ESP32-C6 FireBeetle 2 Mini).

Option A: Web Uploader (Visual UI) 1. Launch start-uploader.bat in the repository.
2. Open http://localhost:3567 in Chrome.
3. Flash 1 board as c6WIFILED_MASTER.
4. Flash remaining boards as c6WIFILED_FOLLOWER.
Option B: One-Click Batch Scripts Execute helper scripts directly in the codebase repo:
• upload_c6_master.bat
• upload_c6_follower.bat
