Haptic Engineering & Software Tools

Rust Audio-to-Smartphone Haptics Daemon

High-performance Windows-to-Android tactile feedback daemon written in Rust. Captures direct system audio loopback via WASAPI, processes sound through real-time Biquad Butterworth filters, and streams native vibration commands directly over USB ADB with zero acoustic feedback.
