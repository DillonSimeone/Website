# Augmented Reality Book Project

> [!NOTE]
> **Status: Archived Exploration**
> This prototype was an interactive augmented reality exploration designed for *Gravity Falls*. 
> 
> The project explored markerless page tracking and surface alignment using MindAR and OpenCV.js. However, current client-side computer vision technology proved too limiting to achieve stable, high-fidelity tracking across physical printed book pages without printing visible QR codes or fiducial tracking markers directly into the book artwork. 
> 
> Kept for internal R&D and archival reference.
