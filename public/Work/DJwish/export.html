🚀 Deploying Nate's Website

1. Unzip & Deploy Anywhere

Extract the downloaded dj-deaf-wish-website.zip. The root folder is completely self-contained with no build steps or bundlers required:

  • GitHub Pages: Push extracted files to a repo & enable Pages in Settings.
  • Netlify: Drag and drop the unzipped folder into Netlify Drop.
  • Vercel / Cloudflare Pages: Connect repo with root directory ./ and zero build command.
  • Shared Hosting: Upload contents to public_html/.

2. AI Agent Instructions Included

Both AGENTS.md and GEMINI.md are packed into the root of the zip file.

They provide full world coordinate maps and step-by-step recipes for AI coding agents to add new "pages" via the 3D cameras whenever Nate has a new gig!
