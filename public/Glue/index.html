1. UNIVERSAL SMARTPHONE SETUP GUIDE

PLUG & PLAY ON ANY ANDROID
1

ACTIVATE USB DEBUGGING

Works on Google Pixel, Samsung Galaxy, Xiaomi, OnePlus, Motorola, or any standard Android phone:

  • Open Settings > About Phone.
  • Tap Build Number 7 times rapidly until you see "You are now a developer!".
  • Go to System > Developer Options and switch on USB Debugging.
  • Plug into PC with a reliable USB cable. When prompted on phone screen, check "Always allow from this computer" and tap Allow.
2

TETHERING CONFIGURATION

Enable high-speed USB data networking between PC and phone:

  • In Developer Options, tap Default USB Configuration and select USB Tethering.
  • Or simply turn on USB Tethering in Network & Internet > Hotspot & Tethering.
  • The native usb-tether.exe daemon handles NCM/RNDIS hardware gadget switching automatically when plugged in.
3

1-CLICK PC INSTALLATION

No Python, no compilers, and no Visual Studio needed! Simply copy the folder:

  • Copy or download the Glue/RUST folder to your desktop or laptop.
  • Double-click Install-Glue.bat.
  • It auto-detects and auto-downloads Google's official platform-tools (ADB) if missing.
  • Registers Windows Startup hooks and starts the entire suite detached in the background!
# Portable Launch & Stop Commands (In Glue\RUST\)
Install-Glue.bat     # Verifies ADB, registers shell:startup, and starts Supervisor + Taskbar Sentinel
Uninstall-Glue.bat   # Cleanly terminates all 6 daemons and unregisters startup shortcuts

3. THE BEFORE & AFTER: PYTHON TO RUST

OVER 88% SYSTEM RAM REDUCTION

WHY THE REWRITE HAPPENED

The original Glue suite was cobbled together using Python (with NumPy, SciPy, PyAudioWPatch, PyStray, Tkinter) and PowerShell scripts. While it functioned, it required massive multi-hundred megabyte Python runtimes, suffered from Garbage Collection (GC) latency spikes during gaming, consumed over 400 MB of system RAM, and required tricky virtual environment management on new machines.

By porting every single utility to 100% native Win32 Rust (compiled via MinGW with LTO and size optimization), the entire ecosystem became completely portable, zero-dependency, and virtually imperceptible to the host operating system.
