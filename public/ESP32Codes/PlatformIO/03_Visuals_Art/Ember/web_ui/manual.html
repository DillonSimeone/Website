1. Studio Tabs & Features

Ambient Tab

Shows a live 50 Hz strip preview, real-time Audio Sensitivity Gate bar, threshold slider X (with 85% hysteresis Y), Audio Gate Fade toggle (2.0 s S-curve attack, 400 ms hold, 3.5 s release), Auto Cycle (default 5 s), and animated pattern cards. Clicking a card runs it immediately and disables Auto Cycle.

Settings Tab

Strip: Live Brightness slider (0..255), Pixel Count (1..600, applies live with zero reboot), and Data Pin (GPIO 0..10, reboots RMT).

Audio: Choose Off, INMP441 (I2S MEMS), or MAX4466 (ADC1 GPIO 0..4 + Soft GND), plus Gain, FFT Smoothing, and 8-band spectrum meter.

Network & OTA: SoftAP password is ember123 (portal 192.168.4.1). Customize AP Name/Hostname, OTA update via /update, or Reset Settings.

Advanced · Pattern Studio

Write pattern expressions with live syntax highlighting, Tab indentation, and Ctrl/Cmd+S save. Edits compile locally first (enforcing exact firmware VM limits) and push live to the strip after 300 ms. Use Common Coding Examples chips to jump-start patterns, or manage LittleFS /patterns/ files under Saved.

2. Language & VM Limits

Your code runs once for every pixel i (0 .. n-1) on every frame at ~50 FPS. Every number is a 32-bit float; end each pixel pass with hsv(h, s, v) or rgb(r, g, b).

CategoryDetails
Built-in varsi / index (pixel 0..n-1), n / pixelCount, t / time (seconds since boot), gate / fade (0..1 gate envelope), PI, TAU (2π)
Conditionalsif (cond) stmt;, if (cond) a; else b;, { s1; s2; } multi-statement blocks, ternary cond ? a : b
Operators+ - * / %, comparisons < <= > >= == != (returns 1/0). Division or modulo by zero safely returns 0.
CommentsSingle-line // comment and block /* comment */
VM LimitsUp to 21 user variables (32 total slots), 255 unique constants, max nesting depth 32, max WS message 4 KB.

5. Tips & Hardware Notes

  • Color output: Call hsv(h, s, v) for FastLED rainbow gradients (h wraps seamlessly cleanly around 0..1), or rgb(r, g, b) for linear RGB blends. Only the last color call per pixel is drawn.
  • Pin rules (ESP32-C3): MAX4466 ADC input must use ADC1 (GPIO 0..4). Keep LED Data Pin (default GPIO 5) separate from mic pins and avoid strapping pins (GPIO 8/9) for output.
  • Captive portal: Connecting to Ember-XXXX or Ember-Audio-XXXX (password ember123) automatically opens http://192.168.4.1.
