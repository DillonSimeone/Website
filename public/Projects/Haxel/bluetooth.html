Web Bluetooth Mode

This page allows you to control Haxel hardware directly using Chrome's **Web Bluetooth API**. No local network or WiFi configuration is required. As long as your Haxel unit is in Bluetooth Mode, you can pair with it and stream real-time haptic commands directly.

To start, make sure your Haxel unit is powered on and its Bluetooth/WiFi configuration is set to Bluetooth. You can pair and connect directly using the button below:
