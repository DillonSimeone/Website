Chrome Captioning Hijacker

A creative accessibility hack built during the Windows 10 era to bring Live Captioning to Discord, video calls, and desktop meeting platforms before system-wide OS captioning existed.

It routed desktop audio through a virtual audio cable into Chrome to trigger its high-accuracy, on-device WebSpeech live captioning engine, then used an OBS virtual camera feed to overlay floating subtitles into any application.

Windows 11 Evolution: Windows 11 now features native, system-wide Live Captions accessible anytime via the keyboard shortcut Win + Ctrl + L. Beyond transcribing system and speaker audio, Windows 11 includes a dedicated setting to include microphone audio—enabling instant, offline speech-to-text for plugged-in microphones and in-person conversations without requiring browser hijacks or virtual cable routing.
