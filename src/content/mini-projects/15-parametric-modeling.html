Parametric Modeling & PCB Configurator

I used to design 3D models entirely by hand, but I have found that building out parametric models is far more superior. Crafting models using code and parameters feels like a return to the original ancient magic, where math, logic, and structure define form. The same approach works for circuit boards: an interactive configurator builds, routes, and compiles custom WS2812B LED light strip arrays in the browser with TypeScript, Three.js, and tscircuit.
